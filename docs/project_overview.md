# Project charter and management question

**Question:** Under which operating assumptions does Microsoft generate durable free cash flow, and which drivers should management prioritize?

**Company choice:** Microsoft is a U.S.-listed non-financial operating company with a June 30 fiscal year, an understandable software/cloud business, at least five comparable annual disclosures and usable SEC XBRL data. Capital intensity provides a clear management question. The selection supports an aggregate annual MVP; it does not imply that all segments have identical economics.

**Scope:** FY2022–2026 original annual facts, FY2027–2029 projections, three operating scenarios, two sensitivity families and four one-year historical holdouts. FY2019–2021 supply warmup observations. Annual-only snapshot as of November 7, 2026; interim FY2027 information is outside the model.

**Outputs:** linked Excel financial statements; reproducible Python transformations; keyed SQLite facts; interactive browser dashboard; four-page financial report; two-page executive memo; seven-slide walkthrough; source and model validation evidence.

**Analytical approach:** Complete historical reconciliation before projection. Separate reported actuals from analyst assumptions and forward estimates. Use transparent accounting linkages, a disclosed minimum-cash borrowing rule and a simple historical baseline. Preserve misses and model limitations.

**Portfolio framing:** Independent public-data finance analysis. No company sponsorship, production FP&A implementation, realized savings or improved company earnings are claimed. Power BI and GitHub Pages are optional extensions; the public repository itself is the source handoff.
